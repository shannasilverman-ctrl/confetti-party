# Acceptance contract

1. A signed-out visitor can understand the product and start with text or voice.
2. Every seeded demo has an event visual and meaningful data for overview,
   guests, Bring Board, shopping, budget, checklist, and timeline.
3. Guest invites and workspace chrome do not cover content at 320, 375, 390,
   430, 768, or 1440px.
4. Local planning presents venue, food, and at-home paths appropriate to the
   occasion and guest count; third-party searches are clearly labeled and never
   presented as booked, rated, available, or endorsed inventory.
5. Every visible control leads to a real implemented state, route, or explicit
   setup step. No dead buttons or fabricated success.
6. The brand remains recognizably Confetti: rich party photography, expressive
   type, plum/coral color, kinetic delight with reduced-motion support, and
   readable contrast.
7. Format, lint, typecheck, unit/integration tests, production build, bundle
   budget, dependency audit, responsive Playwright, and accessibility checks pass.
8. Production release is performed only after the exact commit is green in
   GitHub CI and the deployed `/release.json` matches that full SHA.
