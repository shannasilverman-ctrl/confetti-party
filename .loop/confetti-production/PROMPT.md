# Destination

Make Confetti the most thoughtful consumer party-planning companion: a host
can start with one messy idea, leave details blank, and receive a complete but
editable path through venue/at-home choices, food, guests, contributions,
shopping, budget, setup, day-of execution, and memories.

## Customer-backwards rules

- Reduce the host's next decision to the smallest useful choice.
- Never turn an unknown into a fake fact.
- Distinguish Confetti-curated ideas from live third-party inventory.
- Never invent ratings, reviews, prices, availability, bookings, or “nearby.”
- Treat birthdays, weddings, holidays, Shabbat, cookouts, dinner parties, and
  game-day gatherings as first-class compositions, not one-off templates.
- Preserve the joyful Confetti visual system through every workflow, while
  keeping text readable and controls calm.
- Mobile is the primary interaction surface: 44px targets, safe areas, keyboard
  resilience, thumb reach, reduced motion, and no fixed chrome over content.
- Demo mode must be complete enough to evaluate every major feature without
  touching production data.

## Boundaries

No deployment, DNS, billing, messages, purchases, credentials, real-user
mutation, or weakening of a quality gate inside the loop.
